## Install

<div class="install-grid">

<div class="install-card">
<div class="install-label">macOS / Linux</div>

```bash
curl -fsSL https://raw.githubusercontent.com/sageil/kodacode/main/install.sh | sh
```

</div>

<div class="install-card">
<div class="install-label">Homebrew</div>

```bash
brew tap sageil/tap && brew install --cask kodacode
```

</div>

<div class="install-card">
<div class="install-label">Go</div>

```bash
go install github.com/sageil/kodacode/cmd/kodacode@latest
```

Search is built into the app. No separate search binary is required.

</div>

</div>

Then run `kodacode` to start.

</div>
