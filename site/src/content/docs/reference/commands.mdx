Type `/` in the input to open the fuzzy command menu, or press `Ctrl+P` to open the **command palette**, a unified fuzzy finder for files, symbols, sessions, and commands.

## Command Palette

Press `Ctrl+P` to open the command palette. It searches across four categories:

- **Files**: project files (from `git ls-files`). Selecting one attaches the file to your next message.
- **Symbols**: workspace symbols via LSP. Type `@query` to search. Selecting one attaches the symbol's file.
- **Sessions**: existing sessions. Type `#query` to prioritize them. Selecting one resumes the session.
- **Commands**: slash commands. Type `/query` to prioritize them. Selecting one runs the command.

The palette uses fuzzy matching with scoring for consecutive matches, word boundaries, and camelCase. Results update as you type.

## Cost and Trace Workflows

Use `/cost` during a long session to see whether spend is coming from prompt growth, heavy subagent usage, or repeated model/tool loops.

When `session.trace: true` is enabled, `/cost` adds a per-turn table and `/trace N` lets you inspect a single turn's:

- input/output/cache tokens
- retries and fallback usage
- tool timing
- prompt segment mix

Typical workflow:

```
/cost
/trace 4
```

That is the fastest way to answer practical questions such as "why did this turn suddenly get slow?", "which workflow is blowing up my token bill?", or "did compaction actually help here?".

## Subagent Delegation

Invoke any agent directly as a slash command. These launch a subagent session:

| Command | Description |
|---------|-------------|
| `/explorer [question]` | Research codebase (read-only, uses utility model) |
| `/insight [task]` | Extract learnings and persist to AGENTS.md |
| `/polish [task]` | Clean up AI-generated code artifacts |
| `/planner [task]` | Create structured implementation plan |
| `/refactor [task]` | Restructure code without changing behavior |

### Examples

```
/explorer how does the authentication flow work?
/planner add rate limiting to the API endpoints
/polish src/handler.go
/refactor extract database queries into a repository layer
/insight
```

Custom agents you create are also available as slash commands using their filename (without `.md`).

## Fuzzy Autocomplete

All commands support fuzzy matching. Type `/exp` to match `/explorer` and `/export`. The menu filters as you type, showing up to 8 completions with prefix matches ranked first.
