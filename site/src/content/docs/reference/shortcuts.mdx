Use [Navigation Keys](/reference/navigation/) for the current verified key map.

That page covers:

- pane focus and drawer movement
- composer shortcuts such as inline prompt recall (`Up` / `Down`), searchable history (`Ctrl+R`), external editor handoff (`Ctrl+E`), `@` path mentions, `$` skill mentions, and `!` local shell commands
- transcript, tools, and tasks navigation
- copy and paste: transcript visual selection, composer paste (`Ctrl+V`), and platform clipboard requirements
- command palette and management dialogs
- approvals and question prompts
- detail dialogs
- vi-style bindings such as `h`, `j`, `k`, `l`, `g`, and `G`
